# EcoMart | Sustainable E-Commerce Platform

A full-stack, sustainability-focused e-commerce application built with the MERN stack and a Python Flask recommendation microservice.

---

## Prerequisites

* **Node.js** (v16 or higher)
* **Python** (v3.8 or higher)
* **MongoDB** (Local instance or MongoDB Atlas connection string)

---

## Getting Started

To run the complete application, you will need **3 terminal windows** open simultaneously.

### 1. Backend Service (Node.js)

```bash
# Navigate to backend directory
cd MERN-ecommerce-backend

# Install dependencies
npm install

# Start the server
npm start
